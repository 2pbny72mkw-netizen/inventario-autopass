# Sistema de Gestão Autopass — V79.5 REV2

Base: V79.5 REV1 / continuidade da V79.4 REV2.

## Correções
1. **Arrow** — criação e edição de atividades deixam de ser bloqueadas por APT ou pelos indicadores de acesso operacional Metrô, CPTM e Motiva. Os indicadores permanecem no Cadastro/RH para governança, mas não são pré-requisito do planejamento Arrow.
2. **Dashboard Bobinas** — a exibição no menu passa a obedecer diretamente à permissão `field.bobbins_dashboard` (“Visualizar Dashboard Bobinas”), sem amarração por nome de perfil ou metadado legado de roles.
3. **Sobre / Histórico recente** — correção de layout para impedir texto espremido/quebra palavra a palavra.
4. **Versionamento** — aplicação identificada como V79.5 REV2 e histórico atualizado.

## Preservado
Banco, dados, módulos, Coleta de Valores V79–V79.4 REV2, APT/RH, Engenharia/BOM e demais funcionalidades existentes não foram reconstruídos.
