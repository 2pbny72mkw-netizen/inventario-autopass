V66 REV2 — PLATAFORMA OPERACIONAL INTELIGENTE

Principais evoluções:
- GPS obrigatório passa a ser configurável por usuário para Field, Implantação, Gestor Field e Dispatcher.
- Usuários operacionais existentes são migrados com GPS ativo, preservando o comportamento anterior; ADM pode desligar individualmente (ex.: home office).
- Intervalo GPS configurável em Configurações ADM (60 a 1800 segundos; padrão 300 s).
- Previsão dinâmica de conclusão para EMV, Garagem e Recarga.
- Janela histórica configurável por atividade (1 a 30 dias; padrão 3 dias).
- Dashboard exibe ritmo diário, dias estimados, data projetada, tendência e confiança.
- Alterações de exigência de GPS ficam auditadas.
- Histórico Sobre atualizado para V66 REV2.
