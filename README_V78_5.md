# Sistema de Gestão / Inventário Autopass — V78.5

## Engenharia de Produto
- Nova BOM de produto seleciona o item no Cadastro Mestre e herda código, descrição e NCM.
- Subestruturas independentes com código técnico SE001/SE002 e Phantom Item oculto do cadastro mestre.
- Biblioteca de subestruturas reutilizáveis.
- Inclusão permite escolher o ramo/estrutura alvo; níveis N0/N1/N2/N3+ são calculados automaticamente.
- Paletas visuais reforçadas e diferentes para Nacional e Importado; Material/Consumo/Serviço com variações próprias.
- FOB US$ permanece exclusivo para importados.
- Quantidade fracionada continua permitida nos componentes da BOM.
