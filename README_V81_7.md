# V81.7 — Reprogramação de Coletas

- Acesso direto em Programação de Coletas: Sugerir Reprogramação e Propostas salvas.
- Propostas salvas podem ser recuperadas e editadas mesmo sem observação.
- Observação é opcional e não identifica a proposta.
- Data de vigência permanece editável.
- Excel da proposta inclui Programação atual, Programação sugerida e Houve mudança? (SIM/NÃO), com autofiltro.
- Programação vigente só é alterada pela ação Tornar vigente.
- Mantidas as regras de Linha 17/Ouro 2x/mês, demais localidades semanais de terça a sexta, agrupamento por localidade e balanceamento por valor/carga operacional.
