# V81.2

Correção do multiselect das Dashboards de inventário.

- Checkbox persistente para Empresa, Linha, Localidade, Modelo, Status e Tipo.
- Uma ou várias seleções sem Ctrl.
- Seleções preservadas após recarregar os dados da dashboard.
- Hover apenas visual; nunca aplica filtro.
- Clique fora fecha o menu.
- Limpar filtros remove todas as seleções.
- Backend continua recebendo múltiplos valores por parâmetro.
