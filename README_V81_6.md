# V81.6 — Reprogramação formal de coletas

- Preserva a programação vigente enquanto a proposta é simulada/editada.
- Linha 17/Ouro permanece 2x/mês; demais localidades são propostas semanalmente entre terça e sexta.
- Edição manual do dia por localidade, mantendo todos os ATMs da localidade agrupados.
- Gráficos recalculados imediatamente: valor previsto e localidades/pessoas por dia.
- Data de vigência informada manualmente, sem obrigação de início no primeiro dia do mês.
- Fluxo: sugestão → edição → salvar → aprovar → exportar Excel → tornar vigente.
- Propostas e alterações auditadas. Aprovar não altera a programação vigente.
- Exportação oficial identifica vigência e status.
