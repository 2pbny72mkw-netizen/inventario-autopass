# V80 REV4 — ENXUTA

Evolução do Monitoramento da Coleta de Valores.

## Alterações
- Status transacionais A, V, I, VOUCHER, W e O disponíveis na tela principal do Monitoramento.
- Seleção persiste no navegador e controla os cálculos de Transações e Dif. T × D.
- Padrão inicial: A + VOUCHER, conforme validação operacional.
- Modal de ciclo herda automaticamente a regra selecionada no Monitoramento.
- Coluna Dif. T × D agora é ordenável crescente/decrescente.
- Novo Big Number **Divergências T × D** mostra quantidade de ciclos divergentes, saldo e diferença absoluta.
- Clique no Big Number abre os ciclos divergentes para análise e acesso ao detalhe de transações.
- Histórico Sobre atualizado para V80 REV4.
